# HiveLoom

HiveLoom enables real-time, high-performance data processing and auto-scaling across scalable platforms as a robust service.

With HiveLoom, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/HiveLoom.git`
2. `cd HiveLoom`
3. Install in editable mode: `pip install -e .`

## Configuration

HiveLoom is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
